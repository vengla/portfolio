# Hari Haran V — Portfolio
Vite + React + TypeScript, Lenis, GSAP (ticker/tweens), CSS 3D, canvas video-frame stage.

    npm install
    npm run dev

- All content lives in `src/data.ts`. Set `PROFILE.github` to the verified GitHub URL to show GitHub links.
- Replace `public/resume.pdf` (currently a placeholder) with the real résumé.
- Frames: `public/frames/{lg,sm}` + `manifest.json` (generated from the supplied video).
